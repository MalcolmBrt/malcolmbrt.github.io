Engineering Courses

Participation in Pacific Dataviz 2023

As part of the Pacific Dataviz 2023 event, I designed an interactive concept inspired by the "Wheel of Fortune" game. The project randomly selected articles using open-source data provided by the Government of New Caledonia through the data.gouv.nc platform.

Although the original API is no longer available, a demonstration video and the project source code are available on GitHub.

2023

Tutored Project - OPT-NC Waiting Time Interface

As part of my computer science degree, I developed a proof of concept for a web interface displaying real-time waiting times in OPT-NC agencies. The project used data from the OPT public API and was built with Streamlit in Python.

A demo of the application is available on Streamlit Cloud, and the source code can be found on GitHub.

2024

Internship - OPT-NC Postal Codes Search Application

During my final-year internship at OPT-NC, I developed a proof of concept for a web application to search postal codes by locality or P.O. box. The project combined a Spring Boot API and an Angular interface connected to a PostgreSQL database.

A demo of the application is available on GitHub Pages, and the source code is on frontend and backend repositories.

The application has been deployed and is available on Mon Espace OPT-NC.

2024

Mobility

As a student admitted on title in the second year at ENSEEIHT, I unfortunately do not have the opportunity to participate in student mobility programs. To validate an engineering degree, a minimum number of semesters must be completed within the school, which prevents me from benefiting from exchanges abroad.

However, I would have loved to do a mobility in Australia. Having already visited this country and fallen in love with it, I see it as an ideal destination for several reasons. Firstly, Australia is geographically close to New Caledonia, where I lived all my life and where part of my family resides. This proximity would have made the experience less disruptive while allowing me to discover a new culture within the Pacific region.

Moreover, such a mobility would have been an excellent opportunity to improve my English skills. As an engineering student, mastering technical English is crucial, and immersing myself in an English-speaking environment would have accelerated my progress in both professional and everyday communication.

Finally, Australia's pleasant climate, with its sunny days and mild temperatures, would have made the stay enjoyable and conducive to concentration and exploration. Beyond academics, I could have discovered iconic natural sites like the Great Barrier Reef or the Outback, enriching my personal development and broadening my horizons.
